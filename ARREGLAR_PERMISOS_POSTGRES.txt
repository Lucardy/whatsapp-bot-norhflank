ARREGLAR PERMISOS DE POSTGRESQL
═══════════════════════════════════════════════════════

Ejecuta estos comandos en el terminal web del VPS:

───────────────────────────────────────────────────────
PASO 1: Entrar a PostgreSQL como postgres
───────────────────────────────────────────────────────
sudo -u postgres psql

───────────────────────────────────────────────────────
PASO 2: Dar permisos al usuario (dentro de PostgreSQL)
───────────────────────────────────────────────────────
(Dentro del prompt postgres=#, ejecuta estos comandos):

\c whatsapp_bot
GRANT ALL ON SCHEMA public TO whatsapp_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO whatsapp_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO whatsapp_user;
\q

───────────────────────────────────────────────────────
PASO 3: Ejecutar migraciones
───────────────────────────────────────────────────────
cd ~/whatsapp-bot-norhflank
npx prisma migrate deploy

───────────────────────────────────────────────────────
PASO 4: Reiniciar el bot
───────────────────────────────────────────────────────
pm2 restart whatsapp-bot
pm2 logs whatsapp-bot --lines 20
